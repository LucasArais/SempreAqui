# Design

- `logo.png`: logo completa. Duas pessoas que formam um coração em volta de uma casa, com uma mão que acolhe. O coração laranja no alto é o afeto que chega de longe.
- `simbolo.png`: só o símbolo, usado como ícone do app.
- `telas/`: capturas das telas da Fase 0.

## Paleta

| Cor | Hex | Uso |
|---|---|---|
| Azul | `#1767A0` | botões principais, títulos |
| Azul escuro | `#0E4A73` | textos de destaque |
| Verde-água | `#1E9C96` | ícones, sono dentro do habitual |
| Verde claro | `#E3F5F2` | cartões de destaque |
| Laranja | `#F2A33A` | afeto, avisos suaves, sono abaixo do habitual |
| Fundo | `#FBFAF7` | fundo quente, menos cansativo que o branco puro |

Os valores ficam em [app/src/tema.ts](../app/src/tema.ts).
